# V1: MossTTSDelay (8B) → ggml — Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Add native ggml MossTTSDelay (8B) text-to-speech with voice cloning on top of the Foundation codec — `moss-tts-cli tts --text "..." [--reference ref.wav] --out out.wav`, no Python/ONNX/torch at inference.

**Architecture:** A Qwen3-8B backbone (adapted from vibevoice's `qwen2.cpp`, adding per-head q/k RMSNorm) consumes summed multi-channel embeddings and emits hidden states; 33 LM heads produce text + 32×audio logits; a delay-pattern state machine + sampler turn those into RVQ codes autoregressively; the Foundation `Codec` encodes reference audio (cloning) and decodes generated codes → 24 kHz wav. Every op is pinned by a numpy/upstream-python parity fixture.

**Tech Stack:** C++17, ggml (pinned v0.13.0 submodule), GGUF; Python (numpy + gguf + safetensors) for converter + fixtures. Reuses Foundation infra: `model_loader`, `backend` (gallocr path), `audio_io`, `Codec`, `ggml_extend`.

The Qwen3 layer = vibevoice's Qwen2 layer with TWO changes: (a) **no q/k/v/o biases** (Qwen3 has none), (b) **per-head RMSNorm on Q and K** (head_dim-wide `q_norm`/`k_norm`) applied AFTER the q/k projection+reshape-to-heads and BEFORE RoPE. RoPE is NEOX, base from metadata. FFN is SwiGLU. RMSNorm eps from metadata.

namespace moss {
struct Qwen3Hparams { int hidden, n_heads, n_kv_heads, head_dim, intermediate, n_layers, text_vocab; float rope_base, rms_eps; };

    struct ggml_tensor *attn_norm, *attn_q, *attn_k, *attn_v, *attn_o, *q_norm, *k_norm,

// k_past/v_past null on prefill. Returns y + updated full K/V ([head_dim,n_kv,kv,1]).
struct Qwen3LayerOut { struct ggml_tensor *y, *k_full, *v_full; };
Qwen3LayerOut qwen3_layer_forward(struct ggml_context* ctx, struct ggml_tensor* x,
    struct ggml_tensor* pos, struct ggml_tensor* mask, struct ggml_tensor* k_past,

}  // namespace moss

namespace moss {
class DelayBackbone {

    bool load(const ModelLoader& m, int max_seq);   // reads qwen3.* metadata + layers + output_norm

    // Prefill S input-embedding rows (each [hidden]); returns the LAST row's hidden (post final RMSNorm).
    // Resets the KV cache to position 0. embeds: row-major (S*hidden).
    bool prefill(const std::vector<float>& embeds, int S, std::vector<float>* last_hidden);

private:
